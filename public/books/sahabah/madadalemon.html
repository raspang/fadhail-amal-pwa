PINTO-AN I SO KAPANTANG KO MASA A KAMAREGENAN

  2. So Kiyaperang o Anas bin Nadhr
  3. So Kiyaphasada sa Hudeybiah ago so Totholan ko Abu Jandal ago so Abu Basir
  4. So Kiyapag-Islam o Bilal Habashi (Radhiallaho ‘Anho) ago so Kiyarasay Niyan
  5. So Kiyasoled o Abuzar Ghifari ko Islam
  6. So Kiyarasay o Khabbab bin Arat (Radhiallaho ‘Anho)
  7. So Ammar (Radhiallaho ‘Anho) ago so Manga Lokes Iyan
  8. So Kiyasoled o Sohaib (Radhiallaho ‘Anho) ko Islam
  9. So kiyasoled o ‘Umar (Radhiallaho ‘Anho) ko Islam
  10. So Kiyatogalin sa Habasha go so Kiyatapelis o Mbawata-an o Abi Talib ko Paling

PINTO-AN II SO KALEK KO ALLAH

  1. So Kalek o Nabi (Sallallaho ‘Alaihi wa Sallam) ko Igira aden a Sobosobo
  2. Antona-ai ola-ola o Hadrat Anas (Radhiallaho ‘Anho) igira aden a sobo-sobo
  3. So Ola-ola o Nabi (Sallallaho ‘Alaihi wa Sallam) ko Masa a Mimbarahana so Alongan
  4. So Kiyagora-ok o Nabi ko Miyababasa Gawi-i
  5. So Abu Bakr (Radhiallaho ‘Anho) ago so Kalek Iyan ko Allah
  6. So ‘Umar (Radhiallaho ‘Anho) ago so Kalek Iyan ko Allah
  7. So Pangethoma o Abdullah-bin-Abbas (Radhiallaho ‘Anho)
  8. So Kapezagad o Nabi ko Obay o manga Lamba a To-os ko Kiyabinasa o Thamud ko masa a Kapethidawa sa Tabuk
  9. So Da Kapaka-onot o Ka’ab ko Kiyathidawa sa Tabuk ago so Kiyathaubat Iyan
  10. So Kiyapamangethoma-i o Nabi ko Kapezinga o manga Sahabah
  11. So Kalek o Hanzalah ko Kamunafiq
  12. Saba-ad pen a manga Totholan Pantag ko Kalek ko Allah

PINTO-AN III SO KAGENGGEN AGO SO KAPI-ISI KO GINAWA O MANGA SAHABAH

  1. So Kiyasangka-a o Nabi ko Kabaloy o manga Palao a Bolawan
  2. So Kiyasalawada-a o Rasulollah (Sallallaho ‘Alaihi wa Sallam) ko Umar Mipantag ko Kiyapamangeni Niyan sa Maloag a Kapaginetao ago so Kaphati-is a Kapaginetao o Nabi (Sallallaho ‘Alaihi wa Sallam)

  5. So Sokay Ko Oman Gawi-i o ‘Umar Pho-on sa Baitul Mal
  6. So Totholan o Bilal ko Nabi
  7. Salakao pen a Totholan ko Kiyapakasagad sa Gotem o Abu Hurairah
  8. So Pamikiran o Nabi ko Dowa a Tao
  9. So Kapakasagad sa Maregen na Misasarta ko Babaya ko Nabi
  10. So Kiyathidawa a Bebethowan sa Al-Ambar

PINTO-AN IV SO KAPHIYA-PIYA AGO SO KASANGGILA

  1. So Kiyabaling o Nabi (Sallallaho ‘Alaihi wa Sallam) Pho-on ko Kiyakobor ago so Kiyatarima-a Niyan ko Imbitar o Sakatao a Ba-i

PINTO-AN V SO KATHOMANGKEDI KO SAMBAYANG

  1. So Kalbihan o Sambayang a Nafl
