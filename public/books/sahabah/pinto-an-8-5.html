5. So Kalek o Huzaifah (Radhiallaho ‘Anho) ko manga Tiyoba.

So Huzaifah (Radhiallaho ‘Anho) na isa sekaniyan a mala so katawi ron ko manga Sahabah. Aya katawi rekaniyan na ‘Tomatago ko manga Pagenes.’ So Nabi (Sallallaho ‘Alaihi wa Sallam) na miyatharo iyan non so ngaran o manga Munafiq, go piyanothol iyan non so kapakathondo-tondog o manga tiyoba a zagad ko manga Muslim taman ko bangkit. Inibegay niyan non so pakaged-ged (ma-ana so ngaran o phaminasa, so ngaran o manga lokes iyan, go si inged iyan, go so manga ped) o manga tiyoba a phakarambit sa ipho-on sa telo gatos a tao taman sa kadakel iyan. So Huzaifah (Radhiallaho ‘Anho) na pitharo iyan:

“So manga ped a tao na aya iphagiza iran ko Nabi (Sallallaho ‘Alaihi wa Sallam) na so manga pipiya, na saken na aya iphagiza aken non na so manga reregen a mapenggola-ola, ka an aken siran kapagi-iktiyari.’

Piyanothol iyan angka-iya kiyambitiyara-iyan niran ago so Nabi (Sallallaho ‘Alaihi wa Sallam):

So Huzaifah: “Hay Nabi o Allah! Ba kami phakakasoy ko marata, ko oriyan o mapiya a kiya-awidan ka rekami?”

So Nabi: “Oway. Phaka-oma so marata.”

So Huzaifah: “Ba aden peman a mapiya ko oriyan o marata?”

So Nabi: “Huzaifah! Ikaro-o na batiya-a ngka so Qur’an, na pamimikirana ngka so ma-ana niyan na onoti ngka so pando-an niyan.”

Baden miyakala a kalek o Huzaifah (Radhiallaho ‘Anho) na initaros iyan so manga paka-iza iyan ko manga rarata a zagad ko manga Muslim.

So Huzaifah: “Hay Nabi o Allah! Tharo-a ngka raken o ba aden a mapiya a phaka-oma ko oriyan angkanan a marata?”

So Nabi: “Oway. aden den a manga tao a ndadagen niran so manga tao na pagowiten niran ko Naraka.”

So Huzaifah: “Antona-ai zowa-an aken o ra-ot ako angkanan a masa?”

So Nabi: “O aden a sagorompong a manga Muslim a mai-isaisa a sakatao a Amir iran na tapi ka kiran, o da na mbelag ka den ko manga sagorompong na sibay ka ko rogo, o di na si-i ko atag o kayo (sa kalasan) na ron kaon den phata-patay.”

Sabap sa pitharo-on o Nabi (Sallallaho ‘Alaihi wa Sallam) so ngaran o manga Munafiq sangkoto a masa, na lalayon non den iphagiza o ‘Umar (Radhiallaho ‘Anho):

“Ba aden a Munafiq sangka-iya a manga Amir aken?”

Miyaka-isa na minisembag iyan:

“Oway. Aden a sakatao, ogaid na di ko reka petharo-on so ngaran niyan.”

So ‘Umar (Radhiallaho ‘Anho) na kinowa niyan sa kadato so isa, ko kiyasipati niyan non.

Igira aden a miyatay, na so ‘Umar (Radhiallaho ‘Anho) na iphagiza iyan da-an o ndodo-o so Huzaifah (Radhiallaho ‘Anho) sangkoto a zambayangon. O da-on so Huzaifah (Radhiallaho ‘Anho) na so ‘Umar (Radhiallaho ‘Anho) na di sekaniyan zong sangkoto a melebeng.

Kagiya phatay so Huzaifah (Radhiallaho ‘Anho), na penggora-ok sekaniyan sa kalek ago di kasosorot. So manga tao na pitharo iran non:

“Ba aya ngka pekhigora-ok a kapagawa-a ka sangka-iya donya?”

Pitharo iyan. “Kena. Kena ba ko penggora-ok sa pantag san; mababaya ako matay. Penggora-ok ako sabap sa di aken katawan o sangka-iya masa a kangganati aken sangka-iya donya o masoso-at raken so Allah antawa-a ka di.”

Oriyan niyan na piyamangeni niyan:

“Ya Allah! Giya-i so manga mori-pori a masa ko sangka-iya donya. Katawan ka a tatap so kapekhababaya-i aken Reka. Kalimo-on ka so kipetho-ona-an aken Reka.
