11. So Babaya o Manga Sahabah ko Nabi (Sallallaho ‘Alaihi wa Sallam) ago Manga Ped a Iringa.

Aden a miniza ko Ali (Radhiallaho ‘Anho):

“Ay taman a babaya o manga Sahabah ko Nabi (Sallallaho ‘Alaihi wa Sallam)?”

Minisembag iyan:

“Ibet ko Allah! Si-i rekami na so Nabi (Sallallaho ‘Alaihi wa Sallam) na tomo-on nami a di so pathamo-tamokan nami, go so manga wata ami, go so manga ina ami, go tanto ami a mapangingindao a di so kapaka-inom sa matenggao a ig ko masa a kitataralo o kawaw.”

Da den a kiyapanobra o katharo o Ali. Aya kamamata-ani ron na so manga Sahabah na inira-ot siran sangkoto a pangkatan sabap ko katatarotop o Iman niran Da-a salakao san, ko kinipaliyogaten non o Allah ko katharo Iyan

“Tharo-a ngka: A o so manga lokes iyo, go so manga wata iyo, go so manga pagari niyo, go so manga karoma niyo, go so manga tonganay niyo. go so manga tamok a miyasokat. iyo, go so manga dagangan a ipekhawan niyo so kalepas o wakto niyan, go so manga darepa a masoso-at kano ron -na matomo iyo a di so Allah, go so sogo Iyan. go so kapherang si-i ko lalan Rekaniyan; na nayawa niyo taman sa italingoma o Allah so sogo-an Niyan (a siksa): Ka so Allah na di Niyan thoro-on so manga tao a songklid.” (Surah At-Taubah: 24)

Giyangka-iya a Ayaat na mitotoro iyan so paginengka-an a tapa-os ko salakao a nganin a makabira-i ko tao a di so babaya ko Allah ago so Nabi (Sallallaho ‘Alaihi wa Sallam). So Anas (Radhiallaho ‘Anho) ago so Abu Hurairah (Radhiallaho ‘Anho) na piyanothol iran a so Nabi (Sallallaho ‘Alaihi wa Sallam) na miyaka-isa na miya-itharo iyan:

“Di den mabaloy so isa rekano a titho a Mo’min taman sa so babaya iyan raken na di niyan kaombawan so babaya iyan ko manga lokes iyan, go so manga wata iyan ago so langowan a tao ko donya.’

So manga ‘Ulama na pitharo iran a giyangkanan a babaya a miya-aloy sangka-iya Hadith ago si-i ko manga ped a Hadith a lagida-i na giyoto so babaya a pho-on sa mapoti a atay o tao, sa kena ba initegel a babaya. Opama ka giyangkoto a babaya na pho-on sa mapoti a atay o tao, na giyangkoto a katharo a Mo’min (sangkanan a Hadith) na giyoto-i tanda sa piphaporo-an a Iman, a sangka-iya a ibarat na giyoto so manga Sahabah.

So Anas (Radhiallaho ‘Anho) na pitharo iyan a miyaneg iyan so Nabi (Sallallaho ‘Alaihi wa Sallam), “Telo a nganin a o matago ko tao na khata-aman niyan so kamis o titho a paratiyaya, Siran so:

  1. Kabaloy o Allah ago so Sogo Iyan na makalebi a pekhababaya-an niyan a di so salakao kiran sangka-iya donya;
  2. Amay ka aya bo a kakhababaya-i niyan ko nganin na soa-soat ko Allah;
  3. Amay ka ikagowad iyan so kapaka-kasoy ko ‘Kufr’ sa lagid o kikaleken niyan ko kaolog ko apoy”
