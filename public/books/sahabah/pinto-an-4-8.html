8. So Kokoman o Nabi (Sallallaho ‘Alaihi wa Sallam) ko Haram a Pangenengken:

So Nabi (Sallallaho ‘Alaihi wa Sallam) na miyaka-isa na miyatharo iyan:

“So Allah na daden a pa-awing Iyan. Sakamaoto mambo, a aya bo a tharima-an Niyan na so manga soti Inipaliyogat Iyan ko manga Muslim so nganin a inipaliyogat iyan ko manga Nabi Niyan. Pitharo Iyan ko Kitab Iyan:

‘Hay manga Sogo! Kan kano ko manga pipiya [a pangenengken] go nggalebek kano sa mapiya; Mata-an a Saken na si-i ko gi-i niyo nggalebeken na katawan Ko.’ (Surah Al-Mo’minoon: 51)
‘Hay so Miyamaratiyaya! Kan kano ko manga pipiya ko inirizqi Ami rekano...’ (Surah Al-Baqarah: 172)

Oriyan noto na so Nabi (Sallallaho ‘Alaihi wa Sallam) na inaloy niyan angkoto a tao a gi-i melaya-layag a tanto a magogoket so bok iyan ago tanto a boringen so bangkala iyan; a ipoporo iyan so mbala a lima niyan na gi-i niyan tharo-on: “Ya Allah! Ya Allah!” ogaid na so pangenengken niyan, so panginginomen niyan, go so nditaren niyan na langon pho-on sa haram. So mambo so Allah na di Niyan sekaniyan phamakinegen ago di Niyan tharima-an so pangeni niyan, makim pen so mabebetad o mapayag iyan na miyapatot rekaniyan (so tabang o Allah).

Osayan

So manga tao imanto na pephamemesa siran o ino so pangeni o manga Muslim na di lalayon petharima-an o Allah; so sabap na tanto a marayag a kiyasaboti ron sangka-iya Hadith. Makim pen so Allah na petharima-an Niyan so pangeni apiya pho-on sa sakatao a Kafir (liyo pen ko pangeni a pho-on ko baradosa a Muslim), ogaid na mapepento a so bo so pangeni o manga barasimba a pekhasalak baden a di niyan kakhatarima. Giya-i sabap a zisinganinen o manga tao so pangeni o manga tao a barasimba. Aya siyabot si-i na so tao a kabaya iyan a so manga pangeni niyan na lalayon pekhatarima na pananggila-i niyan so manga Haram. Da-a tao a maongangen a ba niyan marao a so pangeni niyan na di tarima-an.
