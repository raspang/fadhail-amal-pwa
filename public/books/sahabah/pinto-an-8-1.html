PINTO-AN VIII SO BABAYA KO ‘ILMO

So Kalimah na aya kiyadiyamongan ko Islam go aya bayanan o langowan a galebek. Da-a mapiya ‘amal a khatarima o daon so paratiyaya ko Kalimah. Giyoto-i sabap a so manga Sahabah, na inibegay iran so langowan o bager iran, balabao ko paganay a manga gawi-i o Islam, si-i ko gi-i kipanolonen ko Kalimah go gi-i siran makithidawa ko langowan o ge-es a iphageren non. Minsan pen so manga galebek iran [sa gi-i kipanolonen ko Kalimah] na aya kiran mala-a miyakatembang, sa maito a minisenggay ran sa kasageb iran ko kalodan o ‘ilmo a paliyogat ko tao so kathomangkedi niyan non, ogaid na so babaya iran sangka-iya okit na minithanan a aya bontal iyan na so kenal ko Qur’an ago so Hadith, a khapakay a kiyabantogan ago marayag a ladiyawan. Igira aden a miyakowa iran a maito a oras a midekha iran ko manga galebek iran a katetembangan kiran sangkoto a masa a paganay pen so Islam, go kagiya ndakel den so manga tao o tomiyarima ko Islam, na so Allah na initoron Niyan angka-iya Ayaat sa Qur’an:

“Na da mapakay ko Miyamaratiyaya o ba siran liyo langon: Na ino da liyo ko omani salompok kiran so saba-ad, ka-an niran pekhasaboti so Agama, go an niran mipephamaka-iktiyar ko pagtao iran igira miyakandod siran kiran, ka an siran maka-iktiyar.” (Surah At-Taubah: 122)

So Abdullah-bin-Abbas (Radhiallaho ‘Anho) na pitharo iyan:

“So manga Ayaat ko Qur’an a minitoron ko paganay pen so Islam, na inipaliyogat iyan ko manga Muslim so kalalakao sa lalan ko Allah, ibarat:

“O di kano sorong ko kambono-ay, na ziksa-an kano o Allah sa siksa a malipedes....” (Surah At-Taubah: 39)
“Sorong kano ko kambono-ay, makhap sa mapened, go panagontamanen niyo so manga tamok iyo go so manga ginawa niyo, si-i ko lalan ko Allah...” (Surah At-Taubah: 41)

Giyangka-iya manga Ayaat na minisambi-on a giyangkoto a paganay a Ayaat, a inithoma niyan ko saba-ad ko omani sagorompong so kalakao iran.”

So manga Sahabah na tanto a maito so bilangan niran, na kiyapangalakowan niran so langowan o pizoko-sokowan a galebek ko Islam. So Allah na inibegay niyan kiran mambo so kababaloy ran a apiya anda khalinga na katawan niyan so zowa-an niran. Si-i ko oriyan o manga Sahabah, na biyaloy o Allah so saba-ad a piyakitabis Iyan kiran so mbaram-barang pizokowan o ‘Ilmo ko Islam. So manga Muhaddithin na pithomangkedan niran so kapanimo-a go kipephanampain ko manga Hadith. Sakamaoto mambo so manga Fuqaha [makalalahar ko manga kokoman ko Islam], so manga Auliya [a manga papasang ko Zikr], so manga Qura (manga papasangi kabatiya sa Qur’an], so manga Mujahideen [manga papasang-i kapakithidawa], go so manga ped iyan, sa omani isa na aden a phitomangked niyan a galebek. Tantowa-i a kinanglan sangkoto a masa, sabap sa o daoto manggola-ola na diden mapiya a kaphakadayamang o mbaram-barang a pizapakan o kata-o ko Islam sabap sa da-a sakatao bo a tao a ba niyan milaham so langowan a sapak o Islam, So bo so manga Nabi [‘Alaihimus Salaam] taman ko Muhammad (Sallallaho ‘Alaihi wa Sallam),a aya iran olowan, na aya bigan sa ge-es a mitoman niyan langon angkanan a miyanga-aaloy Giya-i miyaka-osay o antona-i sabap sa kiya-aloya pen ko totholan ko manga tao a manga ala-i daradat na inaloy pen so totholan kiran sangka-iya a pinto.

1. So Jama’at a Pephangipta ko manga Sahabah:

Minsan pen so manga Sahabah, na mirerengan niran ko galebek iran ko Jihad ago so Tabligh, so kapaganad ago kipephangendaon ko ‘ilmo, na aden pen a Shoorah o manga Sahabah a aya bo sasarigan ko Fatwa (Ipta), apiya si-i ko masa o Nabi (Sallallaho ‘Alaihi wa Sallam). Giyangka-iya a Jama’at na aya ma-aped don na so:

Abu Bakr, so ‘Umar, so Usman, so Ali, so Abdur Rahman-bin-Auf, so Ubai-bin-Kaab, so Abdullah-bin-Mas’ood, so Mo’az-bin-Jabal, so Ammar-bin-Yasir, so Huzaifah, so Salman Farsi, so Zaid-bin-Thabit, so Abu Musa, so Abu Darda (Radhiallaho ‘Anhom).

So kapakabegay sa pamikiran pantag ko Agama si-i ko masa o Nabi (Sallallaho ‘Alaihi wa Sallam) na tanto a mala a paabor sangka-iya manga Sahabah, go makabebetho sa kadalem ago kasasarigi ko ‘ilmo iran.
