12. So Totholan ko Saeed-bin-Jubair (Rahmatullahi ‘Alaihi) ago so Hajjaj Bin Yusuf

Miya-ilay tano so lagidoto a paratiyaya apiya ko miyakatondog kiran (a so manga Tabi’en). Pageposen aken angka-iya pinto ko totholan ko Saeed-bin-Jubair, a sekaniyan na kiyabantogan a Tabi’e. So Nabi (Sallallaho ‘Alaihi wa Sallam) na miyatharo iyan:

“Aya makalelebi a Jihad na so katharo a benar ko hadapan o dato a mangarasi.”

Giya-i tothol ko Jihad a lagid anan. Sangkoto a masa, na so Hajjaj-bin-Yusuf, na marata-i ongar a talibono na aya makandadato. So karangit ago katangarasi o Hajjaj na lomalangkap so totholan non ko bandaran a totholan o manosiya. So manga dato sangkoto a masa, na minsan pen aden a di ran kaphakatarotop, na da siran mibagak o manga ped ko kipephanolonen ko paratiyaya, apiya aya dena katatarima-a tano ron na siran so miyakarata-rata ko manga dato sabao ko kipekhi-abain tano kiran ko manga oontol ago ma-aleken ko Allah a manga dato. Sekaniyan-i saliyanti o datu a so Abdul Malik-bin-Marwan sa Hijaz ago sa Iraq. So datu na si-i babaling sa Damashk na so Hajjaj na si-i matatago so manga pangadapan niyan sa Koofah So Saeed-bin-Jubair na inatowan niyan so Hajjaj ko kiyatampili niyan ko Ibnul-Ash’ath Oriyan o kiyatabana on, na so Saeed (Rahmatullahi ‘Alaihi) na miyalagoy na miyagapas sa Makkah. So parinta na uyago-an niyan sa marangit a gobemador a Makkah sa isosogo-on a kadakep o Saeed. Giyangkoto a gobemador na tinimo iyan so langon o tao sa Makkah na biyatiya iyan kiran so sogo-an o datu a Abdul Malik, a aya oni niyan na:

“Saden sa tao a paka-apasen niyan so Saeed (Rahmatullahi ‘Alaihi) na khasala sa lagid den o kasala-an o Saeed.”

Oriyan niyan na piyakalangkap iyan ko manga tao:

“Ibet ko Allah, ka mata-an a mbono-on aken so tao a paka-apasen niyan so Saeed (Rahmatullahi ‘Alaihi). So pen so walay niyan ago so walay o siringan niyan na thotongen.”

So Saeed na maregen a kiyadakepa on na inowit sekaniyan sa Koofah. Inowit sekaniyan ko danga o Hajjaj. na giyangka-iya a kambitiyara-i na aya miyanggola-ola:

So Hajjaj: “Antay ngaran ka?”

So Saeed: “Aya ngaran aken na so Saeed (ma-ana maginawa).”

So Hajjaj: “Antay ngaran o ama aka?”

So Saeed: “Jubair (ma-ana inalotan).

So Hajjaj: “Di, aya mata-an na seka so Shaqi (ma-ana kiyado-an-do-anan) a wata a mama o Kusair (ma-ana miyaropet a nganin).”

So Saeed: “Lebi a katawan o ina aken so ngaran aken a di seka.”

So Hajjaj: “Do-an do-an ngka na so pen so ina a ka na do-an do-an niyan.”

So Saeed: “Aya mata-o ko misosolen na so Sekaniyan [a Allah].”

So Hajjaj: “Ilaya ngka! Thedaken aken seka a pedang.”

So Saeed: “So ina aken a miyakatoman sa kinibethon niyan raken angka-iya a ngaran.”

So Hajjaj: “Phaki-wit aken seka sa Naraka.”

So Saeed: “O katawi aken a aden a kapa-ar ka san, na miyathay bo a seka-i biyaloy aken a tohan.”

So Hajjaj: “Antona-ai paratiyaya ngka ko Nabi (Sallallaho ‘Alaihi wa Sallam).”

So Saeed: “Sekaniyan so Sogo a Limo ago Nabi o Allah, a siyogo a a-awidan niyan so taralebi a toro-an ko langowan o ka-aden.”

So Hajjaj: “Antawa-ai maporo-i daradat ko manga Khalifah?”

So Saeed: “So isa kiran a kaoombawan niyan so manga ped iyan ko kaso-at o Allah”

So Hajjaj: “Antawa-ai makalelebi kiran a miyaso-at iyan so Allah?”

So Saeed: “Aya bo a mata-o san na so Sekaniyan a Lebi a Mata-o ko misosolen ko manga rareb ago so pagenes o poso.”

So Hajjaj: “Zisi-i sa Sorga so Ali o zisi-i sa Naraka?”

So Saeed: “Aya bo a kakhasembaga ko san na oriyan o kapakasong aken sangkanan a dowa a darepa na mindanga-i aken so manga tao ron.

So Hajjaj: “Antona-ai mapembetad aken ko Gawi-i a Kaphangokom?”

So Saeed: “Da raken da-it o ba ko makakowa so ‘ilmo o gaib”

So Hajjaj: “Di ngka manini-at o ba ngka raken tharo-a so benar.”

So Saeed: “Kena ba ko mambo pephamokhag.”

So Hajjaj: “Ino ka di phakasinga.”

So Saeed: “Da-a ba ko miya-ilay a khisinga aken; go mata-an a ino zinga so tao, a sekaniyan na inaden pho-on sa lopapek, a phakatindeg ko Gawi-i a Kaphangokom a malilibet a manga ringasa

So Hajjaj: “Ogaid na saken na pephakasinga ako.”

So Saeed: “So Allah na inaden ta Niyan a mbida sa dadabi-atan.”

So Hajjaj: “Mbono-on aken seka imanto.”

So Saeed: “So masa ago okit a iphatay aken na andang den a miya-okor.”

So Hajjaj: “Piyakalebi ako reka o Allah.”

So Saeed: “Da a tao a ba niyan miphanakabor so karani niyan ko Allah taman sa di niyan katokawan so paka-mbebetad iyan; go so Allah na Sekaniyan bo-i mata-o ko migagaib.”

So Hajjaj: “Ino aken di miphanakabor so karani aken ko Allah, a saken na si-i ako tampil ko Amir-ul-Mo’minin na sekan na si-i tatampil ko miyamanopak.”

So Saeed: “Si-i ako tatampil ko ped a manga Muslim. Apiya saken na pephalagoyan ko so manga rarata, ogaid na da-a tao a ba niyan masalin so kokoman o Allah.”

So Hajjaj: “Antona-ai mapetharo-o ka ko piyanimo ami a rek o Amir-ul-Mo’minin.”

So Saeed: “Di aken katawan o antona-ai piyanimo iyo rekaniyan.”

(Inisogo o Hajjaj a witen non so manga bolawan, go so manga pirak ago so manga nditaren a pho-on sa Baital Mal na piyaki-ilay niyan ko Saeed.)

So Saeed: “Tantowa-i a phakanggay a gona, asar ka aya makowa ngka misabap kiran na so phakabegay reka sa kalilintad ko Gawi-i a Kalek (ma-ana Gawi-i a Kaphangokom), a sangkoto a masa na apiya so ina na khalipatan niyan so pephakasoso niyan a wata ‘iyan, go so marimimbit na mipembawata iyan so ikaririmbit iyan, go daden a phakanggay a gona sangkoto a masa inonta bo so kapiya-a parangay.”

So Hajjaj: “Ino ba di mapiya angka-iya a miyatimo ami?”

So Saeed: “Sekano-i miyanimo-on na sekano den-i lebi a kokomon.”

So Hajjaj: “Ba da-a khabaya-an ka sangka-i a makowa ngka?”

So Saeed: “Ayabo a khabaya-an aken na so kabaya o Allah.”

So Hajjaj: “Doan-doan ka.”

So Saeed: “Aya doan-doan niyan a tao na so miyapapason so Sorga na si-i phakasoled sa Naraka.”

So Hajjaj: (kiyararangitan) “Tharo-a ngka o antona-a okit-i kambono ako reka “

So Saeed: “Soden so okit a kabaya-a ka a aya raken imbono”

So Hajjaj: “Ba ko seka baden perila-i?”

So Saeed: So rila o Allah na aya titho. So rila-a ka na daden a kipantag iyan.”

So Hajjaj: (Si-i ko pakapephamono-on niyan) “Bono-a ngka a mama ini.”

Somininga so Saeed ko masa a phagowiten ko mbono-an non. Miyatharo-o to ko Hajjaj. Piyakitalowan niyan.

So Hajjaj “Antona-ai minisinga aka?”

So Saeed: “So kaderes ka ko [rara ngit o] Allah, go so ma-ap Iyan reka.”

So Hajjaj: “Mbono-on aken so tao a kiyasabapan sa kiyapaka-thitidawa o manga Muslim. (Si-i ko pephakapamono-on) Bono-a ngka sekaniyan sa danga aken.”

So Saeed “Pakazambayang ako niyo sa dowa ka rak’at”

Oriyan o kiyapakazambayang iyan, na miyadap sa Qiblah na pitharo iyan:

“Mata-an! A saken na ini bantak aken sa hadap aken [ko Allah a] mimba-asko manga langit ago so lopa, a mbabayorantang ako, go di ako ped ko manga pananakoto” (Surah Al-An’am: 79)

So Hajjaj “Bangkiringa niyo sekaniyan ko Qiblat tano na si-i niyo pakasangora ko Qiblat o manga Nasrani, a mizosopaka siran mambo’

So paras iyan na maga-an a kiyabangikiringa on si-i ko salakao a antap

So Saeed:

“...na apiya anda kano pakasangora, na ro-o den so pephangadapan ko Allah....” (Surah Al-Baqarah: 115)

So Hajjaj: “Pakagepha-a niyo. Aya bo a paliyogat reketano na so kapakamamasa niyan “

So Saeed na piyakagepha.

Saeed:

“Inaden Ami sekano a pho-on ko lopa, go ron Ami sekano phakakasoya, go ron Ami sekano phakagemawa sa khaokitan a salakao.” (Surah Taha: 55)

So Hajjaj: “Bono-a ngka sekaniyan “

So Saeed

“Pezaksian ko a daden a tohan inonta so Allah a isa-isa go da-a sakotowa iyan; go pezaksian ko a so Muhammad na Sogo o Allah. Siyapa ngka (angka-iya a Kalimah) ka amay ka makatho-ona ta sa Yaomol Qiyamah na kowa-an aken reka bo.”

Piyota-an sekaniyan sa olo.

“Mata-an a reketano o Allah go mata-an a si-i Rekaniyan tano pagendod.”

Oriyan o kiyabono-a on, na tanto a mala a rogo a tomiyoga a pho-on ko lawas o Saeed. Tanto a miyamemesa so Hajjaj. Ini-iza iyan ko manga pamomolong iyan, na pitharo iran:

“So kathatana ago karerenek ko masa a kapatay na da niyan ma-alin so palalagoy o rogo. Kalalayaman, a so manga tao a mbono-on na tanto a pekhalek ko masa a kaphatay niyan sa so rogo na gi-i mbabathik na di phalalagoy phiya-piya.

Osayan

Madakel a miyanggola-ola a lagida-i si-i ko bandaran o totholan ko manga Tabi’in. So Imam Abu Hanifah, so Imam Malik, so Imam Ahmad bin Hambal go so manga ped a Auliya na somiyagad siran sa tanto a masopi-it a tiyoba ago ringasa sabap ko kaphapati-is iran; ogaid na miyatatap iran a ginawa iran si-i ko lalan ko paratiyaya.
