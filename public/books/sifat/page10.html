Ta’lim

Antap o Ta’lim - 4

  1. Pakapheraraden ko poso so manga Katharo o Allah (Subhanaho wa Ta’ala) ago so (Sogo Iyan a) Rasulollah (Sallallaho ‘Alaihi wa Sallam).
  2. Phamola-an ko manga poso so babaya ko kanggalebek sa mapiya ago so kapananggila-i ko marata.
  3. So kapaka-khampeta ko ‘Ilmo ago so ‘Amal (galebek).
  4. So kapanagombalay o Yaqin (mabager a paratiyaya) ko (kanggalebek sa) A’mal.

Kalbihan

So Abu Hurairah (Radhiallaho ‘Anho) ago so Abu Sa’id (Radhiallaho ‘Anho) na palaya mizakesi sa miyatharo o Nabi (Sallallaho ‘Alaihi wa Sallam), “So kalilimod a mata laman ko taden-tadem ko Allah na lilibeten o manga Mala-ikat. So limo o Allah ago so Sakinah (kalilintad a mokama) na pethoron kiran ago so Allah na alowin Niyan siran ko lebi a mapiya ago maporo a kalilimod; (giyoto) so kalilimod o manga Mala-ikat.” (Muslim, Tirmidhi)

Pat (4) Timan a “Ta” ko Ta’lim

  1. Ta’dhim - Phaki-ilay so pithamanan a pada-adat ko manga katharo o Allah (Subhanaho wa Ta’ala) ago so Hadith o Nabi (Sallallaho ‘Alaihi wa Sallam).
  2. Tasdiq - So katangkeda ago kasarig (Yaqin) ko Barakah o manga katharo o Nabi (Sallallaho ‘Alaihi wa Sallam) taros o kaparatiya-a ko kabebenar iran.
  3. Ta’mil - So kinggolalanen ko manga Ayat sa Qur’an ago so manga Ahadith a miyabatiya sa Ta’lim.
  4. Tabligh - So kisampain non ko manga ped.

Telo a Pimba-adan o Ta’lim

Melagi-lagid so kalendo o oras a izenggay sangka-iya telo ba-ad (o Ta’lim):

  1. Mbatiya-an so Fadhail-e-Qur’an oriyan niyan na Mudhakarah ko manga Surah (mbatiya-an so mori a sapolo a manga Surah).
    Aya thanodan ko antap o Surah Mudhakarah na dowa a batang a “S” ago dowa a batang a “C”:
    • S - Sunnah (so okit a kabatiya)
    • S - Sawab (so balas o kabatiya)
    • C - Correction (so kapaka-ontola ko pembatiya)
    • C - Concentration (so katekhesa ko pamikiran)
  2. Mbatiya-an so Fadhail-e-A’mal ago so Fadhail-e-Sadaqat.
  3. Mudhakarah ko nem a sifat.

Okit-okit o Ta’lim - 13

  1. So kapamakot ko mabalaga (ko darepa a ron so) Ta’lim
  2. So kaosar sa Miswak
  3. So kadadalem ko abdas
  4. So kakhakamotan
  5. So kazambayang sa dowa ka rak’at a Sunnat

    Khapakay a mbida-bida so ni-at (sangkoto a dowa ka rak’at a Sunnat, lagid o Tahiyyatul Wudhu, Tahiyyatul Masjid, Salatul Hajat, Salatut Taubah, go so lagid iyan).

  6. So kaontod sa lagid o kaontod sa tahiyat igira gi-i ta sambayang
  7. So kaontod rakhes o kapamamakineg phiya-piya
  8. So karena ko babaya sa katharo, kainom sa ig, go so manga ped iyan a salakao san
  9. So kazinganina ko Sorga igira miya-aloy so kapiya o Sorga
  10. So kikaleken ko Naraka igira miya-aloy so pakaleklek ago so manga kasiksa-an non
  11. So kasalawat igira miya-aloy so ngaran o Nabi (Sallallaho ‘Alaihi wa Sallam)
  12. So kaphed ko Ta’lim ipho-on sa poonan na taman sa kaposan
  13. So kabatiya pho-on ko pimbarang a pinto ko kitab
