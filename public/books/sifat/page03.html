Manga Kalbihan a Giyangka-iya Ummat

“Miya-aden kano a mapiya a pagetao, a piyakagemaw ko manga manosiya, a ipezogo iyo so okit a mapiya, go ipezapar iyo so marata, go paparatiyaya-an niyo so Allah.” (Surah Ali ‘Imran: 110)

Miyapanothol a so ‘Umar (Radhiallaho ‘Anho) na miyatharo iyan, “Saden sa tao a kabaya iyan a maped sangkanan a pagetao (ma-ana mapiya a pagetao), na tomanen niyan so manga sarat a tiyago-on o Allah (ma-ana izogo iyan so mapiya go izapar iyan so marata).” (Tafsir Ibni Kathir)
