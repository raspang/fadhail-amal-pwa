So Nem a Sifat

Ika Pat a Sifat - Ikram-e-Muslimin (So Kapagadati ko manga Muslimin)

Antap

So kapagadati ago so kibegan ko kabenar o omani Muslim ka an maparihala so manga A’mal tano ko Gawi-i a Qiyamah.

Kalbihan

  1. So Allah (Subhanaho wa Ta’ala) na thabangan Niyan so oripen Niyan si-i ko tenday a kapethabangi o oripen ko manga pagari niyan a manga Muslim. (Muslim)
  2. O pagema-a tano so manga karibatan o manga ped tano, na pagema-an mambo o Allah so manga karibatan tano ko Gawi-i a Qiyamah. (Muslim)

Okit a Kakhakowa-a Sangka-iya Sifat

  1. Da’wat: So kapanolon sangor ko Akhlaq (paparangayan) o Nabi (Sallallaho ‘Alaihi wa Sallam) ago so kibegan ko manga kabenar o omani Muslim.
  2. Amali Mashq (Kasalin sa panarima):
    • So kapagadati ko mato-a, go so kikapedi-in ko kangoda-an, go so kapagadati ko manga Ulama.
    • So kapakaadiya-diya ta ko manga ped minsan pen kasisikotan ta mambo.
      “...go inilawan iran ko manga ginawa iran, apiya pen aden a zisi-i kiran a kamiskin...” (Surah Al-Hashr: 9)
    • Ithoman so nem a kabenar o omani Muslim:
      1. O mabalak ka so Muslim na salama ngka.
      2. O imbitara ka niyan na tarima-a ngka.
      3. O pangeni reka sa Mashwarah na begi ngka sa tolabos a mapiya a Mashwarah.
      4. O maka-mbaan na tharo-on niyan so Alhamdolillah, na sembaga ngka sa katharo-a ngka o Yarhamukallah.
      5. Bentelen ka igira pekhasakit.
      6. O mawafat sekaniyan na pangeped ka ko Janazah (ma-ana phaigo-on, khapanen, zambayangan, taros a ikhobor). (Muslim)
  3. Du’a: So kapangeniya ko Allah ko kapadalem o Haqiqat (kathithowan) o Ikram ko manga poso tano.
